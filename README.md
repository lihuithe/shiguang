# 拾光（ShiGuang）

像刷短视频一样随机回顾照片和视频，看到废片顺手一删。功能对标 iOS App「去留 - 照片整理与随机回顾」，**不需要登录，没有订阅，没有每日浏览上限**。

## 功能与交互

底部是系统原生 TabView：**照片 / 视频 / 统计**。用 Xcode 26 编译、在 iOS 26 上运行时，Tab 栏和圆形按钮是原生液态玻璃。

| 页面 | 交互 |
|---|---|
| 照片首页 | 三张扇形叠放的卡片，背景取照片主色；轻触「开始回顾」；左上角下拉切换分类（照片、截图、实况、动图、自拍），角标是本组剩余数量 |
| 照片浏览 | 顶部：返回、组内进度条、分享。中间是圆角照片卡片：左右滑切换、双击收藏、双指捏合进入「回到那天」、长图轻点全屏查看；实况照片左上角「实况 ⌄」可切换自动播放与静音。底部：收藏、「时间 · 地点 ⓘ」、删除、撤销 |
| 删除 | 照片和视频都是**点删除按钮**才删（不支持上滑删除，避免误操作）。删除后画面缩小飞进动态岛并闪红光，立即从序列移除，提示「点击 ↶ 可以撤销」；看完一组再统一确认 |
| 一组结束 | 滑过最后一张，或中途返回时有待删除项，会弹出「有待删除的照片 / 视频」：默认全选，点缩略图可取消勾选留下；照片选「放弃，回到首页」或「确认删除」，视频选「放弃，继续看」或「确认删除」；确认后由系统再确认一次，删除的内容进入「最近删除」，30 天内可恢复 |
| 回到那天 | 照片缩进一条左右滑动的多排时间轴，不止当天，可一路滑到前后的日子，顶部日期跟着变。顶部：返回、筛选（全部 / 照片 / 视频 / 截图）、日期、✓ 完成。底部：回到起点、时间刻度尺（拖动快速穿越时间）、撤销。格子可上滑删除；双指缩放切换 2 排或 3 排，放大到底回到照片；轻点格子放大查看，可左右翻、点删除按钮删除。按 ✓ 才真正删除，有待删除时按返回会先询问 |
| 视频 | 抖音式：上下滑一次一支，画面占「屏幕顶部到 Tab 栏上缘」，Tab 栏后面是纯黑底；视频比例自动适配（接近屏幕比例的竖屏视频铺满，横屏和接近方形的完整显示并居中）。轻点暂停 / 播放；长按 2 倍速（显示「2× 快进中」），松手恢复；拖动底部进度条跳转，画面显示「当前 / 总长」。右侧收藏、分享、删除、撤销；左下角时间与地点，点击看详细信息。首次播放询问「视频会自动播放声音，要继续吗？」 |
| 统计 | 照片 / 截屏 / 视频各自的查看、删除、清理；腾出空间与各类占比；重置浏览记录；右上角齿轮进入设置 |
| 详细信息 | 拍摄时间、距今、地点（反查中文地名）、类型、尺寸、大小、文件名，以及「回到那天」入口 |
| 首次引导 | 「左右滑动切换照片」提示；看到第 3 张时弹出「回到那天」捏合教学；时间轴首次显示操作提示 |

其他：每组 5–100 张；看过的内容 3 年内不重复，全部看完后用最早看过的补齐并提示重置；HDR（低亮度自动关闭）；iCloud 同步浏览记录；每日回顾提醒；演示模式（用生成的示范卡片代替真实照片，方便录屏）。

## 目录结构

```
quliu-app/
├── project.yml                  # XcodeGen 工程描述
├── App/                         # iOS App（SwiftUI + PhotoKit）
│   ├── ShiGuangApp.swift        # 入口、原生 TabView、权限引导页
│   ├── AppModel.swift           # 全局状态：设置、浏览记录、统计、iCloud 同步、时间轴数据
│   ├── Components/              # 照片分页浏览器 SwipePager、只接上滑的 UIKit 手势、玻璃按钮、动态岛红光、进度条
│   ├── Photos/                  # 照片首页（扇形卡片）、照片浏览页
│   ├── Videos/                  # 视频信息流（自控三页分页）
│   ├── Review/                  # 照片 / 视频共用的浏览状态机、待删除清单、详细信息、捏合教学
│   ├── Day/                     # 回到那天（多排时间轴、筛选、刻度尺、放大查看）
│   ├── Media/                   # 照片 / HDR / 实况 / 动图 / 长图 / 演示卡片；视频播放与可拖动进度条
│   ├── Stats/  Settings/
│   ├── Services/                # PhotoKit、媒体加载、地名反查、主色提取、分享、持久化、触感、通知
│   └── Resources/Assets.xcassets
├── Packages/ShiGuangCore/       # 纯 Swift 核心逻辑 + 单元测试（不依赖 UIKit）
└── scripts/
    ├── make_icon.py             # 生成 App 图标（python scripts/make_icon.py，需要 Pillow）
    └── lint_brackets.py         # 无编译器环境下的括号配对检查
```

核心逻辑都在 `ShiGuangCore`：

- `GroupPicker`：随机抽一组，跳过近期看过的内容
- `GroupSession`：组内位置、删除即移出序列、撤销放回原位、外部删除后保持进度
- `ViewHistory`：浏览记录，以及 iCloud 多设备合并
- `TimelineLayout` / `TimelineSearch`：「回到那天」的多排瀑布流排版与按时间查找
- `SwipeClassifier`：翻页、捏合等手势判定
- `UsageStats`：按照片 / 截屏 / 视频分类统计
- `AppSettings`：设置及旧版本数据的兼容解码
- 日期与容量格式化

## 构建（需要 macOS + Xcode 26）

```bash
git clone https://cnb.cool/epiphanymind/quliu-app.git
cd quliu-app
brew install xcodegen
xcodegen generate
open ShiGuang.xcodeproj
```

- 最低系统：iOS / iPadOS 18；在 iOS 26 上 Tab 栏与按钮使用原生液态玻璃。
- 在 Xcode 的 Signing & Capabilities 中选择你的开发团队，并把 `PRODUCT_BUNDLE_IDENTIFIER`（`project.yml` 中为 `com.example.shiguang`）改成你自己的。
- iCloud 同步使用 `com.apple.developer.ubiquity-kvstore-identifier` 权限。**免费开发者账号不支持 iCloud**，签名会失败；这时可删除 `project.yml` 中的 `entitlements` 段落后重新执行 `xcodegen generate`，App 仍可正常使用，只是同步不生效。
- `ShiGuang.xcodeproj` 由 XcodeGen 生成，不纳入版本控制；拉取新代码后如有新增文件，重新执行 `xcodegen generate`。

## 测试

```bash
cd Packages/ShiGuangCore
swift test
```

也可以在 Xcode 中对 `ShiGuang` scheme 执行 Test（⌘U）。单元测试覆盖：

- 随机抽组不重复、看完后用最早看过的补齐
- 浏览记录的重复窗口与多设备合并
- 删除即移出序列、撤销放回原位、翻页不计入撤销、外部删除后保持进度
- 时间轴瀑布流排版与按时间查找
- 翻页、删除、捏合的手势判定
- 按类别统计与腾出空间占比
- 设置与统计数据的旧版本兼容解码
- 日期、时长与容量格式化

## 已知限制

- 「照片」分类用 PhotoKit 谓词排除截图，但 GIF 仍可能出现在「照片」里（PhotoKit 无法按播放样式筛选）。
- 腾出的空间通过 `PHAssetResource` 的 `fileSize` 估算，是近似值。
- iCloud 键值存储单个值上限 1 MB，浏览记录过多时只同步最近的部分。
- 「回到那天」每次只载入锚点照片前后各 200 项，滑到两端会停下，不会自动继续往外加载。
- 动态岛红光的位置按 iPhone 15 Pro / 16 Pro 估算，其他机型可能有偏差。
